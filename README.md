# Cielos de la Orinoquía — boletín

Noticias de NASA Ciencia en español, con recursos educativos relacionados de NASA Space Place. Actualización semanal los viernes; sin API de IA y sin despliegues en Netlify.

El contenido educativo es una guía temática, no una explicación específica del descubrimiento. Las fechas de publicación se conservan. Si una consulta falla se conserva la edición anterior.

No conectar este repositorio a los despliegues automáticos de Netlify: la app consulta solamente `boletin.json`.
